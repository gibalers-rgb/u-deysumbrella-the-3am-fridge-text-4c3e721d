A program that writes the one line a smart fridge texts its owner at 3am.

Run it with Node 22: `node main.ts`. It writes a single line of at most 140
characters to `/output/entry.txt`, no network, no keys, no input — the whole
joke is composed in `main.ts`.

The line: a fridge that kept receipts on the last of the cake, has the light
logs, and threatens to send them to the group chat at sunrise.
